# Design Letters – produktkontroll (bokstaver)

Kilde: klient (jj), Slack 6. okt 2026: «heart jewellery (little big love) is ok but all the letters are not looking like real life. You need to build some kind of q check against each letter x size used.» Feil: bail-plassering, bokstavform, størrelse, bail-form (deres er skarpere). «It is the details and feministic minimalistic shape which sets us apart.»

## Regel
Hver bokstav i hver annonse sjekkes mot ekte produktbilde FØR levering. Helst: bruk ekte produktfoto/cut-out (Filecamp eller designletters.dk) i stedet for AI-genererte bokstaver. AI forvrenger Arne Jacobsen-formene.

## Sjekk per bokstav × størrelse
| # | Punkt | Hva du ser etter |
|---|---|---|
| 1 | Bokstavform | Identisk med produktbildet: tykkelse, kurver, avslutninger (Arne Jacobsen, tynn og minimalistisk) |
| 2 | Størrelse | 10 / 16 / 30 mm. Riktig proporsjon mot kjede, hals og hånd |
| 3 | Bail-plassering | Samme sted på bokstaven som på produktet (sjekk hver bokstav, den varierer) |
| 4 | Bail-form | Skarp, smal og avlang som på produktet. Ikke rund/myk |
| 5 | Kjede | Riktig type og tykkelse (Guld kæde = ankerkjede 0,8 mm, Square Link ca. 1 mm) |
| 6 | Henging | Hver bokstav henger separat, ingen overlapp |
